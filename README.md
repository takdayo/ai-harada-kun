# ⚡ AIはらだくん × 英文法制覇

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/takdayo/ai-harada-kun)

カッコよくてかわいいAIロボット「AIはらだくん」が、**英文法ぜんぶ**をチャットで教えて、**1,583問の3種タイマー付きクイズ**でビシバシ鍛えてくれる超絶アプリ。

- 🤖 **AIチャット**：Poe API（Claude / GPT / Gemini など好きなボット）でストリーミング応答（100%オンライン仕様）
- 🎯 **クイズモード**：**超絶英文法問題 1,583問**を25章×3形式で出題
  - **4択** 1,124問 — 20秒タイマー
  - **並べかえ** 172問 — 60秒タイマー、語句チップをクリックで組み立て
  - **記述／書きかえ／誤文訂正** 287問 — 40秒、自己採点 + AI解説
- 💡 **AIはらだくん解説**：どの問題も「💡 解説してもらう」ボタンでPoe API が即ストリーミング解説
- 🗑️ **チャットクリアボタン**：いつでも会話をリセットして最初から
- 🚀 **GitHub + Render で即デプロイ**：`render.yaml` 同梱で1クリック対応

## 💬 チャットの聞き方サンプル

| こう聞くと…  | こう動く |
|---|---|
| `受動態って何？` | AIが文法解説をストリーミング |
| `仮定法過去と過去完了の違いは？` | 同上 |
| `問題を出して` | 🎯 全章ランダム10問スタート |
| `受動態の問題を出して` | 受動態の章から10問 |
| `関係詞のクイズ` | 関係詞の章から10問 |
| `イディオムの問題` | イディオム章から10問 |
| `53問の問題を出して` | 問題 No.53 を単問出題 |
| `問題1234` | 問題 No.1234 を単問出題 |
| `Q.789` | 問題 No.789 を単問出題 |

> 番号は **1〜1596** が指定可能（途中、原本でスキップされた番号もあります）。
> 章名キーワードは時制・受動態・助動詞・仮定法・不定詞・動名詞・分詞・関係詞・接続詞・前置詞・比較・主述の一致・疑問文・否定・語順・話法・動詞/名詞/代名詞/形容詞/副詞の語法・イディオム・会話表現・ボキャブラリー・文構造 すべてに対応。

## 🏃 ローカルで動かす

```bash
npm install
cp .env.example .env
# .env を編集して POE_API_KEY を設定
npm start
# → http://localhost:3000
```

Node.js 20+ が必要です。

## 🚀 GitHub + Render デプロイ手順（超絶完結版）

### 1. GitHub に push

```bash
git init
git add .
git commit -m "feat: AIはらだくん×文法制覇 初版"
git branch -M main
git remote add origin https://github.com/<あなた>/ai-harada-kun.git
git push -u origin main
```

### 2. Poe API キーを取得

1. https://poe.com にログイン
2. https://poe.com/api_key でAPIキーを発行・コピー

### 3. Render で Blueprint デプロイ

1. https://dashboard.render.com にログイン
2. **New +** → **Blueprint** を選択
3. 先ほどpushしたGitHubリポジトリを選択
4. `render.yaml` が自動検出される → **Apply**
5. 環境変数 `POE_API_KEY` に Poe のAPIキーを貼り付け → **Deploy**

数分後、`https://ai-harada-kun.onrender.com` のような URL でアクセス可能になります。

### 4. ボットの変更（任意）

Render のダッシュボード → Environment → `POE_BOT` で変更：

| ボット名 | 特徴 |
|---|---|
| `Claude-Sonnet-4.5`（デフォルト） | 日本語・解説が丁寧 |
| `GPT-5` | 万能、応答スピード◎ |
| `Gemini-2.5-Pro` | 長文・例文豊富 |
| `GPT-4o-Mini` | 高速・低コスト |

## 🔧 API

| エンドポイント | 説明 |
|---|---|
| `GET /api/health` | サーバー状態・APIキー有無・使用中ボット名を返す |
| `POST /api/chat` | `{messages:[{role,content}]}` を受け取り、Poeにプロキシして SSE で返す |

リクエスト例：
```bash
curl -N -X POST http://localhost:3000/api/chat \
  -H 'Content-Type: application/json' \
  -d '{"messages":[{"role":"user","content":"受動態って何？"}]}'
```
